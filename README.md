# Retail Sales Analytics Dashboard

## Project Overview
This project analyzes retail sales data using Microsoft Excel. The dashboard provides insights into sales performance, profit, product categories, and regional performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## KPIs
- Total Sales: 108.08M
- Total Profit: 12.88M
- Total Orders: 2843
- Profit Margin: 12%

## Key Insights
- Technology category contributed around 50% of total sales.
- South region generated the highest sales.
- Phone was the top-selling product.
- July recorded the lowest monthly sales.
